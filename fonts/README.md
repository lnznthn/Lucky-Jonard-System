# Fonts

These files are served with the app so it can draw its text with no network connection.

| File | Typeface | Source package |
| --- | --- | --- |
| `bebas-neue-latin-400-normal.woff2` | Bebas Neue 400 | `@fontsource/bebas-neue` 5.3.0 |
| `geist-sans-latin-400-normal.woff2` | Geist 400 | `@fontsource/geist-sans` 5.3.0 |
| `geist-sans-latin-500-normal.woff2` | Geist 500 | `@fontsource/geist-sans` 5.3.0 |
| `geist-sans-latin-600-normal.woff2` | Geist 600 | `@fontsource/geist-sans` 5.3.0 |

Only the latin subset is included. Both typefaces are licensed under the SIL Open Font License, Version 1.1 (https://openfontlicense.org). Bebas Neue is copyright 2019 The Bebas Neue Project Authors; Geist is copyright 2023 Vercel, made in collaboration with basement.studio.

The latin subsets do not contain the peso sign (₱), so the browser draws that one character with a system font.
